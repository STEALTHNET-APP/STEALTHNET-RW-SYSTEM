# RollyPay: поле «ID кассы»

- В «Настройки → Оплата → RollyPay» появилось поле «ID кассы (Terminal ID)». Если RollyPay отвечает «terminal_id is required», впишите туда UUID кассы: панель передаст его при создании счёта, проверке статуса оплаты, запросе баланса и чтении настроек кассы.
- Поле можно оставить пустым, если RollyPay сама определяет кассу по API-ключу: такие установки работают как раньше.
- «Проверить подключение» теперь пишет понятно: «RollyPay просит ID кассы», «ID кассы не подходит к API-ключу» или «не совпадает с кассой ключа». Если RollyPay знает кассу ключа, проверка подскажет её ID.
- При оплате ответ «terminal_id is required» тоже переводится: «RollyPay просит ID кассы».
