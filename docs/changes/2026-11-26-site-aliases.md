# Дополнительные домены

- Старые и запасные домены можно перевести на панель: впишите их в `SN_SITE_ALIASES` в `deploy/.env` и выполните `stealthnet restart`.
- Адреса на этих доменах переадресуются на основной домен с тем же путём, сертификаты выпускаются сами.
- Подробности — в руководстве по установке, раздел «Дополнительные домены».
