# Lava.top: продажа только подписками

- Если продаёте через Lava.top только подписками, «ID оффера» можно оставить пустым. Для этого нужно включить «Автопродление через Lava.top» и привязать хотя бы одну подписку. Клиент тогда видит у привязанных сроков только «Карту с автопродлением», разовые способы не показываются. Где «ID оффера» заполнен, всё работает как раньше.
- «Проверить подключение» без «ID оффера» спокойно пишет, что разовые оплаты выключены и для них нужен отдельный продукт с «Ценой по запросу API».
- Если в «ID оффера» стоит оффер подписки, проверка советует указать оффер отдельного разового продукта или очистить поле, если нужны только подписки.
- Строка проверки про подписки Lava.top показывает только, сколько их привязано к срокам тарифов.
