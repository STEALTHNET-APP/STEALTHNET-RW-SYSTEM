# Поддержка: длинный список и закрытие старых обращений

- Раздел «Поддержка» помещается в окно, как мессенджер: список прокручивается в своей колонке, переписка — в своей, поле ответа всегда внизу. Выбор обращения не сбрасывает прокрутку списка.
- Список подгружается по 50 обращений при прокрутке, а поиск, «Ждут ответа», «Ответ дан» и «Закрытые» ищут по всем обращениям. На телефоне список и переписка — отдельные экраны со стрелкой «Назад», на узком экране данные клиента открываются кнопкой «Клиент».
- «Выбрать» над списком: отметьте обращения и закройте их разом. «Закрыть старые» закрывает обращения, которые ждут ответа дольше заданного числа дней, если клиент за это время не писал; окно сначала показывает, сколько закроется. Клиентам ничего не приходит, в журнал действий попадает одна запись с числом.
- «Главная», блок «Ноды»: название ноды в одну строку, длинное обрезается многоточием, полное — во всплывающей подсказке. Страна с флагом — мелко после названия, если не помещается, остаётся только флаг; «онлайн» — справа.
