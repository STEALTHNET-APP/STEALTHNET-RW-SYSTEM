# Lava.top: служебная почта старой панели больше не ломает оплату

- У клиентов, перенесённых из старой панели, почтой входа могла стоять служебная `tg_…@telegram.local`. Панель отправляла её в Lava.top, и Lava.top отклоняла счёт: «Invalid customer email».
- Теперь адреса на служебных доменах (`.local`, `.localhost`, `.invalid`, `.internal`, `.home.arpa`) почтой для оплаты не считаются. Бот перед счётом один раз спросит настоящую почту и продолжит ту же оплату. В кабинете и мини-приложении появится поле «Почта для чека».
- Такой адрес нельзя ввести и в «Почту для чека»: бот и кабинет ответят, что в почте опечатка.
