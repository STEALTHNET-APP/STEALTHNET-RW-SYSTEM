# Свой CSS кабинета на сайте

- Новый раздел «Настройки → Кабинет на сайте»: «Общий CSS» на весь кабинет и CSS отдельных разделов — шапки, входа, подписки, подключения, тарифов и оплаты, устройств, пополнения, друзей, подарков, помощи, безопасности и ссылок внизу. Правила раздела действуют только внутри него.
- Живое превью на выдуманных данных: экраны кабинета, новый клиент, с подпиской и с закончившейся подпиской, компьютер и телефон, обе темы, язык. Стили видны до сохранения, ошибка подписана строкой и причиной, есть заготовки правил и загрузка картинок.
- Общий CSS действует и на вход с оплатой: после правки проверьте в превью экраны «Вход», «Тарифы» и «Пополнение». Лендинг, мини-приложение, страница оплаты и админка не меняются; если файл стилей не загрузился, кабинет откроется без него.
- Классы, переменные цветов и примеры — в руководстве «Кабинет на сайте».
