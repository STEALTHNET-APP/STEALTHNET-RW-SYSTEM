# Автопродление через Lava.top

- В «Настройки → Оплата → Lava.top» появились переключатель «Автопродление через Lava.top» и список «Подписки Lava.top»: подписку Lava.top можно привязать к сроку тарифа с той же ценой. По умолчанию всё выключено, разовые оплаты Lava.top работают как раньше.
- Клиент выбирает способ «Карта с автопродлением» при оплате привязанного срока. Дальше Lava.top сама списывает деньги раз в срок, а панель продлевает подписку по её уведомлению, один раз на каждое списание. Пока у подписки автопродление Lava.top, с баланса за неё не списывается и доп. устройства не докупаются.
- Отключить можно в кабинете, мини-приложении и боте, оператор — в карточке клиента (там же «Сверить с Lava.top»). Отмены и неудачные списания в Lava.top, смена тарифа, блокировка клиента и чарджбэк тоже закрывают автопродление; клиент получает сообщение.
- Панель сама сверяется с Lava.top, если уведомление потерялось, а спорные случаи кладёт в «Деньги → Ждут решения».
