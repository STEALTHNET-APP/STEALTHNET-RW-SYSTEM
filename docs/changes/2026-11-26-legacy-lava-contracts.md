# Перенос договоров Lava.top и повтор списаний из журнала

- Перенос со старой STEALTHNET больше не теряет счета Lava.top старше 30 дней. Старая панель часто не замечала первую оплату Lava.top, и счёт оставался неоплаченным, хотя Lava.top каждый месяц списывает деньги по договору. Теперь новая панель запоминает такие договоры при любом сроке, и списания по ним продлевают подписку. Старую ссылку на оплату по таким счетам панель не предлагает. В проверке переноса они стоят отдельной строкой, повторный перенос их не удаляет.
- Если списание пришло раньше, чем договор появился в панели, в «Деньги → Уведомления платёжек» оно отмечено «Пропущено: продление подписки, которой нет в панели». Теперь у такого уведомления есть кнопка «Обработать ещё раз»: когда договор появится, например после повторного переноса, нажмите её, и списание проведётся по договору. Перед этим панель спрашивает у Lava.top, подтверждает ли она списание.
- Если списание провёл договор старой панели, оповещение «зачислите вручную» по этому списанию закрывается само с пометкой «Зачислено автоматически по счёту старой панели». Раньше оно оставалось открытым, и деньги можно было зачислить второй раз.
- Если такое оповещение уже закрыли вручную, повторить уведомление нельзя: деньги могли зачислить вручную. Панель покажет дату и пометку закрытия.
