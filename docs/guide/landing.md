# Лендинг

«Настройки → Лендинг» — страница сервиса на домене панели. Слева блоки, справа живое превью: «Компьютер» или «Телефон», «Светлая» или «Тёмная». На телефоне превью открывается кнопкой «Превью». На сайт правки попадают после «Сохранить», «Отменить» возвращает сохранённое.

Страница работает, пока включён модуль «Лендинг». Если он выключен, главная ведёт в кабинет, а лендинг можно готовить: клиенты увидят его после включения.

## Блоки

Первый экран, преимущества, как подключиться, тарифы, серверы и приложения, вопросы и ответы, призыв в конце и подвал. Блок раскрывается на месте: тексты, кнопки, ссылки, картинки, пункт в меню сайта. Блоки можно скрывать и менять местами, первый экран всегда сверху, подвал — внизу. Тарифы, цены, сроки и страны берутся из каталога сами. Если у каждого тарифа на продаже один срок, сроки у них разные, а устройства, трафик и серверы одинаковые (например, каждая категория — отдельный срок), блок «Тарифы» показывает их все сразу одной сеткой, без переключателя; на телефоне по умолчанию выбран второй.

Стандартные тексты показываются на языке посетителя, свои — как написаны. «Вернуть стандартный блок» возвращает один блок, «Вернуть стандартный лендинг» — всю страницу: тексты, порядок, картинки и свой CSS.

## Свой CSS

Вид лендинга можно поменять стилями. Полей два вида:

- **«CSS блока»** — внизу каждого раскрытого блока. Правила действуют только внутри этого блока, поэтому селекторы короткие: `h1`, `.ld-card`. До 10 000 символов.
- **«Общий CSS»** — последняя строка списка. Действует на всю страницу: цвета, шапка, кнопки. До 50 000 символов.

Превью показывает стили сразу, ещё до сохранения. У блоков со своим CSS в списке подписано «свой CSS».

CSS действует только на лендинг. Кабинет, мини-приложение, страница оплаты, страницы документов и админка не меняются, и сломать их стилями нельзя. У мини-приложения свои стили: [Мини-приложение, «Свой CSS»](miniapp.md).

**Если в CSS ошибка**, под полем появится строка и причина, например «Строка 7: не закрыта скобка {» — нажмите на неё, чтобы перейти к строке. Пока ошибка не исправлена, «Сохранить» недоступна, а превью показывает последний правильный вариант.

**Помощь под полем.** «Вставить правило для…» вставляет заготовку для части блока: заголовка, кнопки, карточки тарифа. «Загрузить картинку» кладёт файл на ваш сервер (PNG, JPEG, WebP до 1 МБ) и вставляет его адрес. «Сбросить» очищает поле. Tab добавляет отступ, а чтобы выйти из поля с клавиатуры, нажмите Escape и Tab.

### Что писать

В «CSS блока» свойства без селектора относятся к самому блоку, `&` — тоже он:

```css
background: #eef6f4;

h1 {
  font-size: 92px;
}

&:hover .ld-btn {
  opacity: 0.9;
}
```

Фон первого экрана на всю ширину окна:

```css
max-width: none;
padding-inline: max(24px, calc(50% - 576px));
background: #e8f3f1;

[data-theme='dark'] {
  background: #10211f;
}

.ld-phone {
  padding-bottom: 32px;
}
```

Цвета всей страницы — в «Общем CSS», переменными у `.ld`:

```css
.ld {
  --accent: #0f766e;
  --accent-ink: #0f766e;
  --btn: #0f766e;
  --btn-ink: #ffffff;
}
```

Выделить карточку тарифа — в «CSS блока» у тарифов:

```css
.ld-card:nth-child(2) {
  border-color: #0f766e;
  background: #e8f3f1;
}
```

В «CSS блока» `[data-theme='dark'] { … }` и `.ld-phone { … }` — это сам блок в тёмной теме и на телефоне.

Тёмная тема и телефон в любом поле:

```css
[data-theme='dark'] h2 {
  color: #9be3d4;
}

@media (max-width: 600px) {
  h2 {
    font-size: 24px;
  }
}
```

На телефоне у части элементов свои размеры. Если правило там не действует, начните селектор с `.ld-phone`: `.ld-phone .ld-btn { border-radius: 8px; }`.

### Классы

| Часть страницы | Селекторы |
| --- | --- |
| Вся страница | `.ld`, на телефоне ещё `.ld-phone` |
| Шапка | `.ld-head`, `.ld-brand` (логотип и название), `.ld-nav a` (меню) |
| Любой блок | `.ld-sec`, заголовок `h2`, `[data-block='plans']` и так далее: `hero`, `features`, `steps`, `plans`, `servers`, `faq`, `cta`, `footer` |
| Кнопки и ссылки | `.ld-btn` (главная), `.ld-btn2` (обычная), `.ld-link` |
| Первый экран | `.ld-hero`, `h1`, `.ld-lead` (текст), `.ld-hero-text > .ld-muted` (строка под кнопками), `.ld-art` (стандартная картинка), `.ld-pic-img` (своя) |
| Преимущества | `.ld-item`, `.ld-item h3`, `.ld-item p`, `.ld-item-pic` |
| Как подключиться | `.ld-item`, `.ld-step` (номер шага, на телефоне `.ld-num`) |
| Тарифы | `.ld-card`, `.ld-card-name`, `.ld-card-price`, `.ld-seg` (переключатель тарифов, с четырьмя и больше — `.ld-seg.many`), `.ld-grid.cards.few` (один-два срока: карточки не шире 400 пикселей), на телефоне `.ld-term` |
| Серверы и приложения | `.ld-item`, `.ld-h2s` (заголовок колонки) |
| Вопросы и ответы | `details`, `summary` (вопрос), `details p` (ответ) |
| Призыв в конце | `.ld-band` (плашка), `.ld-band h2`, `.ld-band p` |
| Подвал | `.ld-foot`, `.ld-foot-brand`, `.ld-foot-nav a` |
| Строка о технических работах | `.ld-notice`, видна, только пока они включены |

Переменные цветов: `--bg` (фон), `--surface` и `--surface-2` (карточки), `--line` и `--card-line` (линии), `--ink`, `--ink-2` и `--muted` (текст), `--accent`, `--accent-ink` (ссылки), `--btn` и `--btn-ink` (главная кнопка), `--band` (плашка в конце), `--btn-dark` и `--btn-dark-ink` (кнопка на плашке).

### Что не принимается

- `@import` и другие способы подключить чужой файл: скопируйте правила в поле.
- Адреса других сайтов в `url()`. Запрос к чужому серверу выдал бы ему IP-адрес каждого посетителя, а политика CSP сайта всё равно разрешает картинки и шрифты только со своего домена. Подойдут картинки, загруженные кнопкой под полем, файлы с вашего домена (`url("/static/bg.png")`) и `data:` с картинкой или шрифтом.
- `javascript:`, `expression()`, `behavior` и `-moz-binding`.
- Теги `<style>` и остальная разметка HTML.

CSS, который не проходит проверку, не сохраняется. При выдаче сайту он проверяется ещё раз.

Стили отдаются отдельным файлом с вашего домена, встроенных стилей на странице нет, поэтому `SN_CSP=all` менять не нужно. Файл виден всем: не пишите в комментариях того, что не должны увидеть посетители.

Менять лендинг и CSS может администратор с правом «Настройки». Журнал действий записывает, в каких полях поменялся CSS и сколько в нём символов, без самого текста.
