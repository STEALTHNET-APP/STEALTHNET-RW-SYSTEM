# Договоры старой панели встают на подписку по привязкам Lava.top

- Договор Lava.top из старой панели теперь находит свой тариф по списку «Подписки Lava.top» в «Настройки → Оплата → Lava.top»: панель сравнивает название подписки Lava.top, периодичность и валюту. Если у клиента несколько подписок, договор продлевает подписку привязанного тарифа, а срок продления берётся из привязки.
- Если привязки нет, договор встаёт на подписку, как раньше: по старым данным или на единственную подписку клиента.
