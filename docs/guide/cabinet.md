# Кабинет на сайте: свой CSS

Вид личного кабинета клиента (`/cabinet`) можно поменять стилями в «Настройки → Кабинет на сайте». Вход, способы входа и что клиент может сам настраиваются в «Настройки → Кабинет и мини-приложение».

## Места

Слева список мест, справа превью кабинета. Раскройте место — появится поле, а превью перейдёт на нужный экран и подсветит раздел. Нажатие на часть кабинета в превью открывает её место.

| Место | Что меняет |
| --- | --- |
| Общий CSS | Весь кабинет, до 50 000 символов |
| Шапка и меню | Логотип, вкладки, баланс, меню профиля, меню на телефоне |
| Вход и регистрация | Экран до входа и экран нового пароля |
| Подписка | Главная кабинета, кроме карточки «Подключение» |
| Подключение | Карточка «Подключение» на главной: устройства, шаги, ссылка, QR-код |
| Тарифы и оплата | Выбор тарифа, срок, способ оплаты, докупка устройств и трафика |
| Устройства | Страница «Устройства» |
| Пополнение и история оплат | Пополнение баланса и список платежей |
| Друзья | Ссылки для приглашения, итоги, вывод |
| Подарки | Покупка подарка, мои подарки, активация кода |
| Помощь | Обращения и переписка |
| Безопасность | Способы входа, почта, пароль, вход по коду |
| Ссылки внизу | Помощь и документы под страницей |

У мест, кроме общего, до 10 000 символов, и правила действуют только внутри своего раздела. У мест со своим CSS в списке подписано «Свой CSS».

**Общий CSS действует на все экраны кабинета, в том числе на вход, «Тарифы», пополнение и кнопку оплаты.** Если правило спрячет кнопку или сделает её текст невидимым, клиент не сможет войти или заплатить. Проверьте в превью экраны «Вход», «Тарифы» и «Пополнение» в светлой и тёмной теме и на телефоне.

Лендинг, мини-приложение, страницы документов, страница оплаты, проверка, страница открытия приложения и админка не меняются.

## Превью

Превью показывает кабинет на выдуманных данных: запросов к вашему серверу оно не делает, настоящие клиенты в нём не видны. Сверху выбираются экран, клиент (новый, с подпиской, подписка закончилась), компьютер или телефон, тема и, если включён английский, язык. «Крупнее» открывает превью на всё окно.

Стили видны сразу, ещё до сохранения. Если в CSS ошибка, под полем появится строка и причина, «Сохранить» будет недоступна, а превью покажет последний правильный вариант. «Вставить правило для…» вставляет заготовку, «Загрузить картинку» кладёт файл на ваш сервер и вставляет его адрес, «Сбросить» очищает поле, «Убрать весь CSS» очищает все места. Клиенты видят изменения после «Сохранить».

## Что писать

Цвета всего кабинета — в «Общем CSS», переменными у `body`:

```css
body {
  --accent: #0f766e;
  --accent-ink: #0f766e;
  --accent-soft: color-mix(in srgb, #0f766e 12%, transparent);
  --btn: #0f766e;
  --btn-ink: #ffffff;
}

[data-theme='dark'] body {
  --bg: #0c1413;
  --surface: #14201e;
  --accent-ink: #5fd0c0;
}
```

`--accent-ink` и `--accent-soft` считаются от стандартного цвета, поэтому при смене `--accent` задайте и их. Переменные пишутся у `body`, а не у `.cb`: экран входа лежит вне `.cb`.

Крупное число дней — в «Подписке»:

```css
.cb-days {
  font-size: 48px;
  color: #0f766e;
}
```

Выбранный срок — в «Тарифах и оплате»:

```css
.cb-term-card[aria-checked='true'] {
  border-width: 2px;
}
```

В CSS раздела `&` — сам раздел, `[data-theme='dark'] …` — он же в тёмной теме, `.cb-phone …` — он же на телефоне.

## Классы

| Часть | Селекторы |
| --- | --- |
| Весь кабинет | `.cb`, на телефоне `.cb.cb-phone`, область страницы `.cb-main-area` |
| Заголовки | `.cb-title` (страницы), `.cb-h1`, `.cb-h2` (карточки), `.cb-lead` (текст под заголовком) |
| Карточки | `.cb-card` |
| Кнопки и ссылки | `.cb-main` (главная), `.cb-second` (обычная), `.cb-text` (текстом), `.cb-accent-link` |
| Поля и переключатели | `.cb-field input`, `.cb-field textarea`, `.cb-seg button`, выбранный — `.cb-seg button[aria-pressed='true']` |
| Состояния | `.cb-status`, `.cb-muted`, `.cb-error`, `.cb-warn` |
| Шапка | `.cb-head`, на телефоне `.cb-phead`, `.cb-mark` (логотип), `.cb-brand-name`, `.cb-tab`, открытая — `.cb-tab[aria-current='page']`, `.cb-balance`, `.cb-ava` (профиль), `.cb-pop` (меню профиля), `.cb-menu`, `.cb-menu-item` (меню на телефоне) |
| Вход | `.cb-solo-box` (окно), `.cb-login-form`, `.cb-login-help` |
| Подписка | `.cb-sub`, `.cb-days`, `.cb-bar`, заполненная часть — `.cb-bar span`, `.cb-balance-card`, `.cb-sum` (баланс), `.cb-auto-row` (автопродление), `.cb-friends`, `.cb-help` |
| Подключение | `.cb-plats button` (устройства), `.cb-step`, `.cb-num` (номер шага), `.cb-step-text` (текст шага) |
| Тарифы и оплата | `.cb-cats button` (тарифы), `.cb-term-card` (срок), `.cb-term-price`, `.cb-term-save`, `.cb-method` (способ оплаты), выбранный — `[aria-checked='true']`, `.cb-total`, `.cb-due-sum` (к оплате) |
| Устройства | `.cb-device`, `.cb-device-text strong` |
| Пополнение и история | `.cb-amount` (сумма), `.cb-payrow` (платёж), `.cb-payrow-side strong` (сумма платежа) |
| Друзья | `.cb-link`, `.cb-facts`, `.cb-withdraw` |
| Подарки | `.cb-giftrow`, `.cb-gift-code` |
| Помощь | `.cb-payrow` (обращение), `.cb-msg`, своё — `.cb-msg.mine` |
| Ссылки внизу | `.cb-foot`, `.cb-foot a` |

Переменные цветов: `--bg` (фон), `--bar` (шапка), `--surface` и `--surface-2` (карточки и кнопки), `--line` и `--card-line` (линии и рамки карточек), `--ink`, `--ink-2` и `--muted` (текст), `--accent`, `--accent-ink` (ссылки и открытая вкладка), `--accent-soft` (фон открытой вкладки), `--btn` и `--btn-ink` (главная кнопка), `--warn` и `--bad` (предупреждения и ошибки).

## Что не принимается

- `@import` и другие способы подключить чужой файл.
- Адреса других сайтов в `url()`. Подойдут картинки, загруженные кнопкой под полем, файлы с вашего домена (`url("/static/bg.png")`) и `data:` с картинкой или шрифтом. Картинки лендинга и мини-приложения в кабинете не подойдут, загрузите их здесь.
- `javascript:`, `expression()`, `behavior` и `-moz-binding`.
- Теги `<style>` и остальная разметка HTML.

Стили отдаются отдельным файлом с вашего домена и подключаются только в кабинете, `SN_CSP=all` менять не нужно. Если файл не загрузился, кабинет откроется без него не позже чем через 2,5 секунды. Файл виден всем: не пишите в комментариях того, что не должны увидеть клиенты.

Менять CSS кабинета могут администраторы с правом «Настройки». В «Журнале действий» видно, в каких местах поменялся CSS и сколько в нём символов, без самого текста.
