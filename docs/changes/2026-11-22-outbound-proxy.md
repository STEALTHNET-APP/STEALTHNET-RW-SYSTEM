# Прокси для Telegram, платёжек и ИИ

- В «Настройки → Бот» появилось поле «Прокси для Telegram», в «Настройки → Платёжки» — «Прокси для платёжных шлюзов», в настройках модуля «ИИ-чат поддержки» — «Прокси для нейросети».
- Поддерживаются SOCKS5, SOCKS5 с удалённым DNS, HTTP и HTTPS, с логином и паролем в адресе или без них. Пароль не показывается в журнале действий и сообщениях об ошибках.
- Прокси из админки применяется сразу, без перезапуска. Если поле пустое, берётся `SN_PROXY_TELEGRAM`, `SN_PROXY_PAYMENTS` или `SN_PROXY_AI`, затем общий `SN_OUTBOUND_PROXY`, `ALL_PROXY` или `HTTPS_PROXY`.
- Если прокси не задан, бот, платёжки и ИИ работают напрямую, как раньше.
