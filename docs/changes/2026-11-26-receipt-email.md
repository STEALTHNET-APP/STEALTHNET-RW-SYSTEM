# Почта для чеков: оплата без почты для входа

- Lava.top и ЮKassa с чеками не выставляют счёт без почты покупателя. Раньше клиенты из Telegram без почты упирались в отказ, теперь панель сама просит почту.
- Бот перед счётом просит прислать почту одним сообщением, проверяет адрес и продолжает ту же оплату. В следующий раз не спрашивает. Перед оплатой видно, куда придёт чек, и почту можно изменить.
- В кабинете и мини-приложении у такого способа в форме оплаты появляется поле «Почта для чека».
- Это отдельная почта для чеков: она не даёт входа на сайт. Оператор видит её в карточке клиента, в журналах она скрыта маской. Для клиентов, у которых почта уже есть, ничего не меняется.
