# Несколько пробных периодов для разных локаций

- В «Тарифах → Пробный период» можно завести несколько пробников: у каждого своё название, срок, устройства, лимит трафика и сквады. Например, «Россия» на 3 дня и «Европа» на 1 день.
- Если пробник один, бот и кабинет выдают его сразу, как раньше. Если несколько — клиент выбирает локацию: в боте кнопкой, в кабинете на карточке подписки.
- Старая настройка с одним пробником продолжает работать без переноса: пока список пробников пуст, панель берёт срок, устройства и сквады из прежних полей.
