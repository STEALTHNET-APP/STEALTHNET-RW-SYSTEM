# Рефералы: проценты уровней коротким списком

- Экран «Пригласить друга» в боте стал короче: «Ваш процент с каждой оплаты:» и по строке на уровень — «35% — друзья», «20% — их друзья», «10% — друзья их друзей». Уровень с нулевым процентом не показывается.
- Тот же список в «Друзьях» кабинета и в карточке «Друзья» мини-приложения.
- Если «Условия», «Второй уровень» или «Третий уровень» уже правились в «Настройки → Бот → Тексты и кнопки», останется свой текст. Новый вид появится после кнопки «Как было» у этих строк. То же с текстом карточки «Друзья» в конструкторе мини-приложения.
