# Профиль мини-приложения: фото, имя и подарок

- «Настройки → Мини-приложение», вкладка «Профиль»: новый блок «Фото и имя» показывает фото, имя и @username клиента из Telegram. Если фото нет или клиент его скрыл, виден значок.
- В блоке «Оплаты и поддержка» — переключатель «Показывать «Подарить подписку»». Клиент видит строку, когда подарки доступны.
- И то и другое по умолчанию выключено: вид у клиентов не меняется, пока вы не включите.
- Для своего CSS — классы `.mn-person` и `.mn-person-photo`, они же в заготовках правил профиля.
- Предложено в PR #24, автор Flecksis.
