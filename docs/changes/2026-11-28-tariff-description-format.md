# Оформление в описании тарифа

- «Описание для клиента» в «Тарифах» — многострочное поле с оформлением как в Telegram: жирный, курсив, подчёркнутый, зачёркнутый и ссылки кнопками над полем или сочетаниями клавиш. «Разметка» показывает те же теги, при вставке из Telegram Web или документа оформление сохраняется.
- Бот показывает описание на экране тарифа с переносами строк и оформлением, многострочное описание отделено пустыми строками. Незакрытые и чужие теги не ломают сообщение, слишком длинное сообщение обрезается без разрыва разметки.
- Лендинг, «Тарифы» в кабинете и мини-приложении и подарки в кабинете показывают первый абзац описания с оформлением и кнопку «Показать полностью». Раньше кабинет и мини-приложение при оплате описание не показывали.
- Старые однострочные описания выглядят как раньше.
