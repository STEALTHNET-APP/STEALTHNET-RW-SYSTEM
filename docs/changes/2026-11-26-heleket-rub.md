# Heleket в рублях и свой адрес API

- Heleket работает и в рублёвых установках: счёт выставляется в рублях, клиент платит любой монетой, Heleket сам пересчитывает сумму. Долларовые установки работают как раньше.
- По рублёвому счёту недоплата и излишек попадают в «Деньги → Ждут решения» с суммой в долларах: Heleket не сообщает, сколько получено в рублях.
- В настройках Heleket поле «Адрес API» принимает только адрес сервера вида https://api.example.com, без пути. Менять его может владелец или администратор с правами «Настройки» и «Деньги», после смены проверка подключения запускается сама.
- Свой адрес API виден строкой под платёжкой, каждая смена пишется в «Журнал действий» со старым и новым адресом.
