# Главная: «сегодня» сравнивается со вчера к этому же времени

- «Главная»: процент рядом с «Заработали сегодня» теперь считается к вчерашней выручке на это же время суток, а не ко всему вчерашнему дню, подпись — «к этому времени вчера». Утром и днём он больше не выглядит провалом только потому, что день ещё не кончился.
- Считается так же, как изменение «Сегодня» в «Аналитике» по строке «без возвратов»: те же оплаты и то же окно вчерашнего дня.
