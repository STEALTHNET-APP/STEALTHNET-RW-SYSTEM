# Новые события автоматических рассылок

- «Счёт создан и не оплачен» — через N часов после неоплаченного счёта на подписку. Правило пишет по последней попытке клиента и только если после неё он ничего не оплатил.
- «Первая покупка» — через N часов после первой оплаченной покупки подписки, например чтобы прислать инструкцию или попросить отзыв.
- «Подписка действует, но давно нет подключений» — после N дней без подключений, один раз на каждый перерыв.
- «Заняты все устройства» — когда подключено столько устройств, сколько позволяет подписка, и тариф продаёт дополнительные.
- В «Заканчивается трафик» можно поставить порог 100 %: правило напишет, когда трафик закончится полностью. Стандартные правила не менялись, новые события добавляются вручную.
