# Сверка автопродлений снова работает, договоры старой панели ищутся по почте

- Сверка автопродлений через Lava.top не запускалась ни разу с 0.1.420: панель не повторяла отмену, если Lava.top не ответила, не находила списания без уведомления и не проверяла договоры из старой панели. Теперь сверка идёт раз в 5 минут.
- Договор из старой панели без номера договора Lava.top (у старой панели там хранился свой номер заказа) панель находит в Lava.top по почте покупателя: почте клиента, почте Telegram или служебной почте `client-…@`. Если у клиента несколько договоров, берётся тот, что совпал с первой оплатой по сумме и дате.
- Если договоры из старой панели ждут проверки, а у Lava.top нет API-ключа, в журнале панели появляется предупреждение.
