# Рефералы: проценты уровней строками в кабинете и мини-приложении

- В «Друзьях» кабинета появился блок «Ваш процент с каждой оплаты». В нём строки «С оплат друзей — 35%», «С оплат их друзей — 20%», «С оплат друзей их друзей — 10%», процент справа. Список текстом под заголовком убран.
- В карточке «Друзья» мини-приложения те же строки, над ними подпись «Ваш процент с каждой оплаты». Подпись меняется в конструкторе: поле «Текст» карточки «Друзья».
- Уровень с нулевым процентом не показывается. Бот по-прежнему показывает проценты коротким списком.
- Свой CSS: в кабинете блок `.cb-levels`, строки `.cb-levels-list`, в мини-приложении строки `.mn-levels`.
