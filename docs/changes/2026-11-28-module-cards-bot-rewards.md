# Модули из архива: раздел в карточке клиента, кнопка в боте и награды

- Модуль из архива может показать свой раздел в карточке клиента: он появляется под «Рефералами», с темой админки и высотой по содержимому.
- В главном меню бота может появиться кнопка модуля со своим экраном. Её место задаётся на вкладке «Порядок кнопок» в ячейке «Кнопки внешних модулей».
- У модуля из архива есть входящий адрес `/api/ext/<модуль>/…`: сторонний сервис шлёт туда запросы, панель пересылает их модулю. Адрес виден в карточке модуля.
- Модуль может выдать клиенту дни, устройства или личный промокод на скидку — ровно один раз на каждую награду. В истории клиента такие действия подписаны названием модуля.
- В событии «Покупка выдана» теперь есть оплаченный срок и число докупленных устройств, добавлено событие «Клиент привязал Telegram».
