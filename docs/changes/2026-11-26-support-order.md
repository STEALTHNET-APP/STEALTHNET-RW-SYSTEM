# Поддержка: сверху новые обращения

- Обращения в «Поддержке» идут по времени последнего сообщения: сверху новые, внизу старые, при прокрутке подгружаются более старые. Порядок одинаковый во всех вкладках и в поиске. Раньше «Ждут ответа» шли от самых давних.
- Новое сообщение клиента поднимает обращение наверх. У обращений, перенесённых из старой панели, время берётся из неё.
- Справа у обращения — сколько прошло с последнего сообщения. С какого времени клиент ждёт ответа, видно во всплывающей подсказке.
- На «Главной» по-прежнему видно, кто ждёт ответа дольше всех.
