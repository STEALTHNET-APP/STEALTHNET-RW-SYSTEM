# Бот: кнопка «Скопировать ссылку» у подписки

- На экране подписки под «Открыть страницу подключения» появилась кнопка «Скопировать ссылку». По нажатию Telegram копирует ссылку подписки, ничего не открывая. Та же кнопка есть в сообщении о новой ссылке после «Выпустить новую ссылку».
- Кнопку можно переставить или скрыть в «Настройки → Бот → Порядок кнопок», надпись меняется в «Тексты и кнопки», раздел «Подписка». Если порядок кнопок уже настраивали, новая кнопка встанет в конец экрана.
- Кнопка копирования работает в Telegram, вышедших с конца 2024 года. Ссылка в тексте сообщения тоже по-прежнему копируется нажатием.
